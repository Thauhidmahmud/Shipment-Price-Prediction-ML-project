# Shipment-Price-Prediction-ML-project

## How to run
Before you run this project make sure you have MongoDB Atlast Account and you have the shipping dataset into it.

Step 1. Cloning the repository.
```
git clone https://github.com/Thauhidmahmud/Shipment-Price-Prediction-ML-project.git
```
Step 2. Create a conda environment.
```
conda create -n shipment python=3.11 -y
```
```
conda activate shipment
```
Step 3. Install the requirements
```
pip install -r requirements.txt
```
